# Online Feedback & Survey System

A web-based **Feedback and Survey System** designed to collect user feedback through an interactive interface and provide a simple way to manage and analyze responses.

## 📌 Project Overview

The Online Feedback & Survey System provides a digital platform for collecting feedback from users through surveys and feedback forms.

The project was developed to replace traditional feedback collection methods with a more convenient and organized online solution.

## ✨ Features

* 📝 Online feedback and survey submission
* 📊 Structured collection of user responses
* 💻 User-friendly interface
* 📱 Responsive web interface
* ⚡ Fast and interactive experience
* 📋 Organized feedback management
* 🔄 Easy-to-use survey workflow

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **React.js**
* **Node.js / npm**

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Swarandip/FEEDBACK-SURVEY-SYSTEM.git
```

### 2. Navigate to the Project

```bash
cd FEEDBACK-SURVEY-SYSTEM
```

### 3. Open the Project Folder

If the main application is inside `DEMO_FEEDBACK-master`, navigate into it:

```bash
cd DEMO_FEEDBACK-master
```

### 4. Install Dependencies

```bash
npm install
```

### 5. Start the Application

```bash
npm start
```

The application should then be available through the local development server.
